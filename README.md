# Developer Portfolio 🚀

An interactive 3D developer portfolio showcasing full-stack development, mobile applications, and modern web experiences. Built with React, TypeScript, Three.js, and GSAP.

---

## 🌟 Highlights

- **Interactive 3D Web Experience**: Custom Three.js character and interactive physics-based tech stack.
- **Featured Projects**:
  - **ResQRoute**: Intelligent disaster-response and evacuation platform (Smart India Hackathon SIH26191) with risk-aware navigation, OSMDroid, and offline token concepts.
  - **Zoom Clone**: Video-conferencing UI exploration focusing on meeting room layouts, speaker tiles, and responsive controls.
- **Structured Tech Stacks**: Categorized breakdown across Frontend, Backend, Mobile (Flutter & Android), Languages, UI/UX & 3D, and Developer Tools.
- **My Journey**: Authentic learning and building milestones.
- **Modern Design Identity**: Deep dark black with purple accents, smooth transitions, and glassmorphic aesthetic.

---

## ⚙️ Tech Stack

- **Core**: React 18, TypeScript, Vite
- **3D & Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`, `@react-three/rapier`
- **Animations**: GSAP, ScrollTrigger, ScrollSmoother
- **Styling**: Vanilla CSS, responsive layouts
- **Icons**: React Icons (FontAwesome 6, Material Icons)

## 🛠️ Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone or download the repository:
   ```bash
   git clone https://github.com/kalpesh0609/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
